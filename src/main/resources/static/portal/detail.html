⏳ VM Agent에서 터널을 여는 중…
SOLID VM에서 아래 명령으로 Agent를 실행하세요:
slink agent start --instance-id

Agent가 Cloudflare Quick Tunnel을 생성하면 공개 URL이 표시됩니다. 이 페이지는 10초마다 자동으로 갱신됩니다.
